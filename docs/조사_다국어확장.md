# 다국어 문구 확장 범위 조사 (P4)

> 상태: 범위 조사(설계 전 단계). 22일 코드 동결 고려한 스코프 제안.
> 기준일: 2026-08-11 · 관련 코드: `generator._localize`, `schemas.CopyRequest.include_en`

## 1. 현황

- 영어 현지화가 이미 옵션으로 있음: `include_en=true` 시 `_localize()`가 한국어
  문구를 영어권 감성으로 transcreation(직역 아닌 재창작).
- 글자 수 제한 별도: `HEADLINE_MAX_EN=40 / SUB_MAX_EN=60` (한글의 약 2배 폭 가정, 임시값).
- 즉 "영어 1개"는 구현됨. 확장 = 언어를 파라미터화하고 언어별 지시/제한을 붙이는 일.

## 2. 확장 목표와 후보 언어

한국어 → 대상 언어 transcreation을 옵션으로 제공. 후보(소상공인 글로벌/K-컬처 타깃 기준):

| 우선 | 언어 | 근거 | 난이도 |
|---|---|---|---|
| 1 | 영어(en) | 이미 구현, 글로벌 공통 | 낮음(완료) |
| 2 | 일본어(ja) | K-푸드·뷰티 인접 시장, 광고 톤 유사 | 중 |
| 3 | 중국어 간체(zh) | 시장 규모, 단 규제·표기 민감 | 중상 |
| 4 | 스페인어(es) | 화자 수 많음, 중남미 | 중 |
| 5 | 프랑스어(fr) | 유럽, 뷰티 친화 | 중 |

- 영어 안에서도 방언 차(미국/영국/호주)는 이번 스코프에서 제외 권장(과분할).
- 최종 5종은 팀 합의로 확정. 위는 조사자 제안일 뿐.

## 3. 방식: transcreation 유지

- 직역이 아니라 문화권 어법에 맞춘 재창작을 유지(현재 영어 방식과 동일).
- 언어별 고려: 글자 수 폭(언어마다 다름), 존대/캐주얼 톤, 통화·단위·관용구.
- 언어별 글자 수 제한은 실측이 필요(현재 영어값도 임시). 폰트 렌더 폭은 이미지
  파트와 연계해 확정.

## 4. 핵심 리스크 — 규제 필터와의 관계 (가장 중요)

우리 서비스의 차별점은 규제 필터인데, **현재 규제 룰·화이트리스트는 한국법
(표시광고법·식품표시광고법·화장품법) 기준**이다. 다국어로 넓히면:

- 각국 광고 규제가 달라, 한국 룰을 그대로 다른 언어 문구에 적용할 수 없다.
- 번역 과정에서 한국어로는 통과된 표현이 대상국 기준으론 위반이 될 수도, 반대일 수도 있다.

→ 안전한 1차 스코프 제안:
1. 규제 검증은 **한국어 원문 기준으로 먼저 통과**시킨 문구만 번역한다
   (생성 파이프라인상 규제 플래그가 safe인 시안만 다국어 대상으로).
2. 대상국별 규제 검증은 **이번 범위에서 제외**하고 로드맵으로 명시(면책 문구 필요).
3. 다국어 결과물에는 "대상국 현지 규제는 별도 확인 필요" 안내를 붙인다.

이 선을 그어야 "규제까지 보장하는 것처럼" 오해되는 리스크를 막는다.

## 5. 제안 아키텍처(설계 방향, 구현 전)

- `include_en: bool` → `target_langs: list[str]`로 일반화(하위호환: include_en=true면 ["en"]).
- 언어별 제한 config: `LANG_LIMITS = {"en": (40,60), "ja": (...), ...}` (값은 실측 후 확정).
- `_localize(lang, ...)`로 언어 인자화, 프롬프트에 언어별 지시 주입.
- 응답 스키마: `localized: {lang: {headline, sub}}` 형태로 확장(현재 headline_en/sub_en은 유지 또는 흡수).

## 6. 22일 코드 동결 고려 스코프 제안

현실적으로 5종 완성 + 각국 규제까지는 무리. 단계 제안:

- 이번(동결 전): 언어 파라미터화 구조 + 영어 확정 + **1~2개 언어(일본어 우선) 구조 검증**.
  규제는 한국어 기준 유지, 다국어 규제는 로드맵.
- 이후: 나머지 언어 추가, 언어별 글자 수 실측, 대상국 규제 대응 설계.

## 7. 미정·확인 필요 (팀 논의)

- 최종 대상 5종 확정(위 후보 검토).
- 언어별 글자 수 제한 실측(이미지 렌더 폭 = 이미지 파트 연계).
- 다국어 폰트 지원 범위(현재 확정 5종은 한글 기준 — 라틴/가나/한자 지원 여부 확인).
- 다국어 규제 면책 문구/UX(대상국 규제 미검증 고지).
