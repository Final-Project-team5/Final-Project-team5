# 규제 필터 면책 고지 & 사전심의 경로 안내

> 목적: "안전장치의 역설"(필터를 믿고 위반 광고를 냈다가 책임 전가) 리스크를 관리.
> 규제 필터의 **한계를 명시**하고, 사용자가 최종 확인할 **공식 경로**를 제공한다.

---

## 1. 면책 고지 (서비스 화면·API 응답에 노출 권장)

**표준 문구**

> 본 규제 검토는 광고 표현의 위반 소지를 **자동으로 참고 안내**하는 기능이며,
> **법률 자문이나 광고 승인이 아닙니다.** `safe` 표시는 "명백한 위반 표현이 발견되지
> 않음"을 뜻할 뿐 **법적 안전을 보장하지 않습니다.** 최종 게시 전 아래 사전심의·자문
> 경로를 통해 확인하시기를 권장합니다.

**판정 단계별 의미 (오해 방지)**

| 표시 | 의미 | 사용자 행동 |
|---|---|---|
| `block` | 명백한 위반 표현 발견 | 수정 필요 (대체 표현 제안 제공) |
| `warn` | 맥락 확인 필요 (근거 있으면 사용 가능) | 근거 확인 후 판단 |
| `safe` | 룰상 명백한 위반 없음 (**안전 보장 아님**) | 필요 시 사전심의 확인 |

---

## 2. 왜 필요한가 (한계 명시)

- 룰은 **명백한 위반을 빠르게 걸러내는 1차 필터**다. 정규식 특성상 **의미를 우회한 표현**
  (예: "면역 쑥쑥")은 놓칠 수 있다. — 골드셋 holdout에서 실측 확인됨.
- 실제 위반 판정은 **개별 제품의 인증 여부·맥락**에 달려 있어, 도구가 100% 대체할 수 없다.
  (예: "OO에 도움을 주는"은 **기능성화장품 인증 제품에 한해** 합법)

---

## 3. 사전심의 · 자문 경로 (업종별)

| 업종 | 기관 | 역할 |
|---|---|---|
| 건강기능식품 | 한국건강기능식품협회 표시·광고 사전심의 (ad.khff.or.kr) | 광고 사전심의 (의무 대상 확인) |
| 화장품 | 대한화장품협회 광고 자문 (kcia.or.kr) | 표시·광고 자문 |
| 식품 일반 | 식품안전나라 / 관할 지자체·식약처 | 부당표시광고 기준 안내 |
| 공통(표시광고) | 공정거래위원회 (ftc.go.kr) | 부당표시광고 유형 기준 |

> 소상공인은 법무 인력이 없어 이런 경로를 모르는 경우가 많다. **"어디서 최종 확인하면
> 되는지"까지 안내**하는 것이 본 서비스의 완결점이자 차별점이다.

---

## 4. 유지보수 원칙 (최신성)

- 규제는 개정된다(예: 화장품 표시·광고 관리 지침 개정, 숙취해소 근거 요건 변경).
- 룰 근거는 `docs/규제근거_출처.md`에 명시하고, **정기 재검증**을 전제로 한다.
- 골드셋(`eval/gold_cases.json`)에 새 위반·회피 사례를 계속 편입해 룰 회귀를 방지한다.
