# AI 생성물 고지 표준안 (v0.1 초안)

작성: 문구모델도혁 | 근거: 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」 제31조

## 왜 필요한가

제31조(인공지능 투명성 확보 의무) 요약:

| 항 | 의무 | 우리 서비스 적용 지점 |
|---|---|---|
| ①항 | 생성형 AI 기반 서비스라는 사실을 **사전 고지** | 프론트 — 서비스 진입/생성 시작 화면 |
| ②항 | 결과물이 생성형 AI로 생성됐다는 사실을 **표시** | 프론트 — 결과 화면 + 다운로드 파일 |
| ③항 | 실제와 구분하기 어려운 이미지는 **명확히 인식 가능한 방식**으로 표시 | 포스터 모델 — 이미지 내 워터마크/표기 |

우리 결과물(실사풍 광고 포스터)은 ③항의 "실제와 구분하기 어려운 이미지"에 해당할
소지가 커서 이미지 자체에 표기하는 것이 안전함.

## 표준 문구 제안

### 1. 이미지 내 표기 (③항 — 포스터모델지우님 파트)

- **문구: `AI 생성 이미지`** (영문 병기 시: `AI-generated`)
- 위치: 이미지 하단 모서리 (문구 오버레이와 겹치지 않는 쪽)
- 형태: 반투명 텍스트 또는 소형 배지. "전시·향유를 저해하지 않는 방식" 허용(③항 단서)이므로
  광고 미관을 해치지 않는 은은한 표기면 충분
- 구현: 후처리(overlay) 단계에서 자동 삽입 → 사용자가 끌 수 없게 (의무 사항이므로)

### 2. 결과 화면 표시 (②항 — 서비스개발소원님 파트)

- 결과 이미지 하단 캡션: **"이 콘텐츠는 생성형 AI로 제작되었습니다."**
- 다운로드 버튼 근처 안내: **"다운로드되는 이미지에는 AI 생성 표기가 포함됩니다."**

### 3. 서비스 사전 고지 (①항 — 서비스개발소원님 파트)

- 첫 생성 시작 화면(업종 선택 단계) 하단 고정 문구:
  **"본 서비스는 생성형 AI를 이용하여 광고 콘텐츠를 제작합니다."**

### 4. 문구(텍스트) 결과물 관련 (문구모델도혁 파트)

- 광고 카피 텍스트도 ②항 대상이므로, 결과 화면의 캡션(2번)으로 이미지와 함께 커버됨
- API 응답에는 이미 `meta.model` 필드로 생성 모델 정보가 포함되어 있어 추적 가능

## 결정 필요 사항 (팀 논의)

1. 이미지 내 표기 문구 확정: `AI 생성 이미지` vs `AI-generated` vs 병기
2. 표기 위치가 문구 오버레이 위치(사용자 선택 좌표)와 충돌할 때 처리 규칙
3. 워터마크 형태(텍스트 vs 배지 아이콘) — 디자인은 프론트/포스터 협의

## 참고

- 시행령에서 세부 표시 방법 규정 예정 → 확정 전까지는 보수적으로(항상 표기) 운영 권장
- 김도혁 공유 자료: AI 기본법 정리 링크 5건 (8/4 디코) 참조
