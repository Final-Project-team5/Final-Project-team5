# 규제 룰 근거·출처 매핑 (방어 자료)

> 목적: 각 규제 룰이 "우리가 정한 기준"이 아니라 **규제기관의 공식 근거**에 있음을 명시.
> 룰(`regulation_rules.py`)의 `reason` 필드는 아래 법령·고시에 대응한다.
> 최종 갱신 기준일: 2026-08 (개정 시 재검증 필요 — 면책 문서 참조)

---

## 카테고리별 근거 체계

| 카테고리 | 1차 근거(법률) | 세부 기준(고시·지침) |
|---|---|---|
| 공통(COMMON) | 표시·광고의 공정화에 관한 법률 | 공정위 「부당한 표시·광고행위의 유형 및 기준 지정고시」 |
| 푸드(FOOD) | 식품 등의 표시·광고에 관한 법률 §8 | 식약처 「식품등의 부당한 표시·광고 내용기준」 / 건강기능식품 기능성 인정 제도 |
| 뷰티(BEAUTY) | 화장품법 §13 | 화장품법 시행규칙 §2(기능성화장품 범위) / 식약처 「화장품 표시·광고 관리 지침」 |
| 굿즈(GOODS) | 상표법 / 표시광고법 | 「환경성 표시·광고에 관한 고시」(그린워싱) |

## 룰 유형별 상세 근거

### 공통 — 표시광고법
- **최상급·확정 표현**("최고", "100%", "완벽") → 공정위 부당표시광고 유형고시: 객관적 근거 없는 최상급·확정적 표현은 부당광고
- **비교광고**("타사 대비") → 근거 없는 비교 금지
- **거짓 긴급성**("오늘만", "선착순") → 실제 조건과 일치해야 함

### 푸드 — 식품표시광고법 §8
- **질병 치료·예방**("치료", "완치", "예방", 특정 질환+효능) → §8①1 질병 예방·치료 효능 표방 금지 (의약품 오인)
- **신체기능 개선**("면역력 강화", "디톡스/노폐물 배출·비우", "피로회복/원기충전", "다이어트 효과") → 건강기능식품 기능성 인정을 받은 문구만 사용 가능
- **천연·무첨가·유기농** → 인증·실증 없는 표현 주의 (내용기준)
- **숙취해소** → 인체적용시험 근거 필요(식약처 고시)

### 뷰티 — 화장품법 §13 + 시행규칙 §2
- **의약품 오인**("치료", "시술효과", 질환명) → §13①1 금지
- **기능성 범위 초과**("주름 제거", "미백 보장", "완전 미백") → 기능성화장품은 "**OO에 도움을 주는**" 수준만 허용 (시행규칙 §2)
- **안전성 단정**("부작용 전혀 없음") → 금지
- 허용 표현 화이트리스트는 `regulation_whitelist.py` 참조 (시행규칙 §2 법정 기능성 종류)

### 굿즈 — 상표법 / 환경성 고시
- **그린워싱**("친환경", "무공해", "에코", "완벽 무해") → 「환경성 표시·광고 고시」: 인증 없는 환경성 주장 주의
- **브랜드 연상**("명품급", "정품보다") → 상표법
- **한정·보증** → 실제 조건 명시

## 공식 출처 링크

- 표시·광고의 공정화에 관한 법률 / 부당표시광고 유형고시 — 국가법령정보센터(law.go.kr), 공정거래위원회(ftc.go.kr)
- 식품 등의 표시·광고에 관한 법률 — https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=234849
- 식품 부당 표시·광고 내용기준 — 식품안전나라(foodsafetykorea.go.kr)
- 화장품법 / 시행규칙(기능성 범위) — 찾기쉬운 생활법령정보(easylaw.go.kr)
- 화장품 표시·광고 관리 지침 — 식품의약품안전처(mfds.go.kr)
- 환경성 표시·광고 고시 — 환경부 / 국가법령정보센터

> ⚠️ 본 매핑은 데모용 1차 정리이며 법률 자문이 아니다. 실제 서비스 적용 시
> 최신 개정본·심의 사례로 재검증이 필요하다. (면책 문서 참조)
